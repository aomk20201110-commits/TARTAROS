\# TARTAROS



TARTAROS is a Unity first-person liminal exploration prototype inspired by brutalist and BABBDI-style spaces.



\## Current Features



\- First-person movement

\- Walking speed and sprint speed

\- Jumping and high-jump pickup

\- Abyss Shard pickup

\- Completion Tool on the upper platform

\- Locked Exit that opens after obtaining the Completion Tool

\- Sealed play area with walls and ceiling

\- Basic win trigger



\## Controls



\- WASD: Move

\- Mouse: Look around

\- Space: Jump

\- Left Shift: Sprint

\- E: Interact with Exit



\## Development Environment



\- Unity 6.4

\- Windows

\- C#



\## Project Structure



The repository includes the Unity source project:



\- `Assets`

\- `Packages`

\- `ProjectSettings`



Generated folders such as `Library`, `Temp`, `Obj`, and `Logs` are excluded by `.gitignore`.
